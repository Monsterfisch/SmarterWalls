# Smarter Walls

Facilite le tracé des murs et corrige les problèmes de réparation des escaliers et des créneaux endommagés. Corrige aussi la pose des échelles contre les murs, ainsi que la façon dont les troupes montent sur les murs et s’y déplacent. Chaque fonctionnalité peut être désactivée dans les paramètres.

En multijoueur, tous les joueurs ont besoin de ce module avec les mêmes paramètres.
