# Smarter Walls

Упрощает возведение стен перетаскиванием и исправляет ошибки при ремонте повреждённых лестниц и зубцов. Также исправляет ошибки при установке штурмовых лестниц у стен, подъёме войск на стены и перемещении по ним. Каждую функцию можно отключить в настройках.

В сетевой игре у всех игроков должен быть установлен этот модуль с одинаковыми настройками.
